Satisfactory Tool — Factory Planner, Save Game Analyzer & Interactive Map

A high-performance, responsive web companion for Coffee Stain Studios' Satisfactory (1.0). Plan, optimize, audit, and visualize your factory production lines and inspect real-world save game files in-browser.

Core Factory Modules & Tools

  • Visual Production Planner (Flow A): Resolve complex recursive recipe trees, compute fractional machine counts, alternate recipes, Somersloop amplification, and visualize multi-tier belt saturation with animated ReactFlow logistics diagrams.
  • Save Game Diagnostics & Analyzer (Flow B): Upload raw Satisfactory binary .sav files directly in the browser to identify logistics bottlenecks, clogged manifolds, machine starvation, and power circuit stability with zero server uploads.
  • Interactive World Map: Full-resolution world cartography with Unreal Engine coordinate translation. Map raw resource nodes with purity tiers, crash sites (hard drives), Mercer Spheres, Somersloops, and power slugs.
  • Power Grid Calculator: Simulate power generation networks across Biomass, Coal, Fuel, Turbo Fuel, Nuclear, and Alien Power Matrix generators with fuse trip alerts and battery reserve tracking.
  • Satisfactory 1.0 Codex: Comprehensive searchable database of all items, buildings, standard recipes, alternate recipes, and AWESOME sink ticket values.
  • FICSIT Blueprint Sandbox: Interactive 8m × 8m foundation grid canvas to design factory floorplans and auto-route conveyor manifolds before building in-game.
